# Al-Masry Sweets Store

An Arabic (RTL) e-commerce storefront for an Egyptian sweets and desserts shop: product catalog, special offers, shopping cart, customer reviews and an admin panel for managing content.

**Live demo:** https://salmantawfeeq.github.io/halwani-elmsry/

## Features

- Product catalog with categories, details pages, ratings and badges
- Offers page and home-page promotions
- Shopping cart
- Customer reviews, FAQ, gallery and contact pages
- Admin panel to manage products, offers and reviews
- Firebase (Firestore and Storage) as the backend; data model and security rules are documented in `firebase-storage-schema.md` and `firestore-security-rules.md`

## Tech Stack

HTML5, CSS3, vanilla JavaScript, Firebase (Firestore, Storage), GitHub Pages.

## Run Locally

Serve the folder with any static server (for example `npx serve .`) and open `index.html`.
